Drawing Checks for Dimension Tables

Five checks that read a pasted table instead of one number: tolerance verdicts, dual-unit conversion with the band carried, round-trip closure, unit mixing, and chain closure.

Paste a dimension table and each tool returns a verdict per row. Nothing is uploaded, the arithmetic is exact to the fraction, and every result exports as CSV.

Five checks, one idea

Every tool on this site converts a number. These five do something different: they take a table and return a verdict per row. The distinction matters because dimensional errors rarely live in a single conversion. They live in a list, one of whose forty rows came from a different revision, or carries a unit nobody noticed, or sits so close to a limit that the next measurement will fall outside.

A converter cannot find those. It answers one value at a time, and it answers correctly, which is why the error survives. A row that was transcribed in the wrong unit converts perfectly into a wrong answer.

The five tools

Tolerance Table Checker Paste nominal, deviations and measured values. Each row is judged against its own limits, and a value sitting exactly on a limit is reported apart from a clean pass. Inspection sheets, receiving checks, first-article reports.
Dual-Unit Dimension Converter Converts nominal and both limits together, then reports what the chosen precision did to the width of the tolerance band. Converting a drawing between inches and millimeters without losing the tolerance.
Round-Trip Conversion Checker Converts each value and converts it back, then reports whether the loop closed and how many decimals it needed. Deciding how many decimals a converted drawing has to carry.
Unit Mix Scanner Finds rows whose unit contradicts the rest of their column, and rows that carry no unit at all. Lists assembled from more than one supplier or revision.
Dimension Chain Closure Calculator Adds a chain of toleranced segments in the worst case and compares the result against a target length. Assembly stacks, slot and clearance checks, shim decisions.

Why these run in the browser

A supplier inspection sheet, a pre-release drawing, a bill of materials from a customer: these are the documents where this kind of checking is worth doing, and they are also the documents that should not be pasted into a web form. Every tool here does its arithmetic in the page. There is no upload, no request, and no server that could log the values. The page works the same way offline once it has loaded.

Exact arithmetic, not floating point

All five checks share the engine behind the site's converters, which carries every value as an exact fraction rather than a floating-point number. This is not a theoretical preference. A limit comparison is decided by whether one number is greater than another, and in floating point a value that should sit exactly on a limit can land a few parts in a quadrillion to one side of it, turning a clean pass into a failure in an inspection report. Adding 3/8 to 5/16 to 1/64 gives exactly 45/64 here, and the comparisons that follow inherit that exactness.

What the export contains

Each tool exports a CSV with one row per input line: the original text, the computed values, the verdict and any note. Keeping the original text in the export is deliberate. It means a second person can audit the output against the source document without re-running anything, which is what makes the file usable as a record rather than as a convenience.

Where these fit

They complement the single-value tools rather than replace them. If you have one dimension to convert, the feet and inches calculator or the batch converter is the shorter route. These pages are for the step after: checking a whole list against what the drawing says it should be.

Questions

Are these tools related to the site converters?

They share the arithmetic engine, so a conversion here and the same conversion on a converter page come from identical exact definitions. What differs is the shape of the input: one table rather than one value, and a verdict rather than a number.

Is any of the pasted data sent anywhere?

No. The checks run entirely in the page with JavaScript, and there is no request carrying the values. That is a deliberate design constraint rather than a marketing point, because the tables these tools are useful on are usually the ones that cannot be shared.

Can the results be printed or saved?

Yes. Each tool exports CSV, and the result table prints with the site layout stripped down so the numbers and verdicts survive on paper. The print stylesheet removes the tool controls and keeps the table.

What if a row cannot be read?

It is listed separately under the result rather than dropped. A silently skipped row is worse than a failed one, because the report then claims to cover a table it did not fully read. The count of unreadable lines appears in the summary.

Do these replace an inspection plan or a GD&T stack?

No. They do arithmetic on the numbers you give them and nothing else. They do not know your drawing standard, they do not apply geometric tolerance or datum shift, and they do not account for measurement uncertainty. They remove the hand arithmetic from a question that gets asked constantly.
